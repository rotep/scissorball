# ScissorBall 36 組立ガイド（rev 1.0）

Kailh PG1425（シザー式）× 36キーの左右分割キーボード。右手親指で操作する25mmトラックボール付きで、左右はTRRSケーブルで有線接続する。

## 1. 仕様

| 項目 | 内容 |
|---|---|
| キー | 片手 5列×3段＋親指（左3・右2）＋右小指下1 ＝ 36キー |
| ピッチ | 18 × 18 mm（カラムスタッガード。ずらし量はKeyball39を18mmピッチへ換算） |
| スイッチ | Kailh PG1425（X Switch）。専用キーキャップが必要 |
| マイコン | Waveshare RP2040-Zero × 2（USB-C） |
| 左右接続 | TRRS（半二重シリアル、GP1） |
| ポインティング | PMW3360（monkeypadブレイクアウト）＋ 25mm玉＋2.5mmセラミック球3点支持 |
| ファーム | QMK（左右共通の1ファイル。左右判定は GP29 のプルアップ/ダウンで行う） |
| 傾斜 | テント10°（親指側が高い）＋手前が高い傾斜5° |

### 段差（机上面からの高さ、右手側）

| 部位 | 高さ |
|---|---|
| 玉の上端 | 36.6 mm |
| 親指キー T1（玉のすぐ左） | 31.6 mm → 玉との差 **5.0 mm** |
| 親指キー T0（最も内側） | 35.5 mm → 差 1.1 mm |
| 人差し指の下段 M | 25.1 mm |
| 小指の上段 P | 13.4 mm（最も低い角） |

傾斜を付けない場合、キー上面は約11.5mmになり、玉との段差は約25mmになる。傾斜とセンサーの床置きによって、この段差を親指キーまわりで5mm前後に抑えている。

## 4. 基板の発注

1. `production/scissorball_left_gerber.zip` と `production/scissorball_right_gerber.zip` を別々に発注する。設定は2層、1.6mm、最小5枚でよい。
2. 各スイッチの下にある 5.1×4.7mm の角穴は、スイッチ底面の突起（深さ約1mm）を逃がすための基板の切り抜き。削除しないこと。
3. 発注前に、`docs/pcb_left_1to1.pdf` / `docs/pcb_right_1to1.pdf` を**実際のサイズ（100%）**で印刷し、スイッチのピン位置と自分の手の大きさを確認することを勧める。

## 6. 組み立て

1. **先にファームを書き込む**：RP2040-Zero の BOOT を押しながらUSBをつなぎ、現れたドライブに `scissorball36_default.uf2` をコピーする。左右とも同じファイルでよい。
2. **ダイオード（裏面）**：シルクのカソード帯（線）側に向きを合わせる。SW2 の脇で1個はんだ付けしたら、テスターで導通方向を確認してから残りを進める。
3. **RP2040-Zero**：表面に、USB-C を基板の外側に向けて平置きする。ピンヘッダの樹脂を外し、ピンを両方の基板に通してはんだ付けした後、表と裏のピンを切る。
4. **TRRSジャック**：基板の内側の縁に取り付ける。
5. **スイッチ**：表から差し込んではんだ付けし、裏に出たピンを**0.5mm以下まで切る**（床とのすき間が1.8mmしかないため）。
6. **センサー基板（右手）**
   - monkeypad の手順どおり、SENSOR面にPMW3360を載せてはんだ付けする。
   - ピンヘッダは付けず、6本の線を直接はんだ付けする：CS、MISO、MOSI、SCK、VCC、GND。MOTION と N/C は未接続でよい。
   - 線はケースの配線溝を通して、メイン基板の J2 につなぐ。J2 のシルクと同じ順番になっている。
7. **ケース（右手）**
   - φ2.5セラミック球3個を、カップ内の斜めの穴に押し込む。固ければ2.5mmドリルで軽くさらい、緩ければ瞬間接着剤を少量使う。
   - センサー基板を**底側から**差し込み、レンズ面を上にしてM2×6で4か所留める。天井側のボスがレンズとボールの距離（7.2mm）を決める基準面になる。
   - 基板をM2で7か所留め、玉を入れてベゼルをM2×6で2か所留める。
8. **ゴム足**を貼る（右手はセンサー基板が底に露出しているので必須）。

> ⚠ TRRSには5Vが流れている。USBをつないだままTRRSを抜き差ししないこと。

## 7. キーマップ（default）

| レイヤー | 呼び出し | 内容 |
|---|---|---|
| 0 BASE | – | QWERTY。親指キー：左 = Alt/無変換・Ctrl/Tab・Space、右 = Enter・Shift/BS・Fn/変換 |
| 1 NUM | 左T0（Space）長押し | 上段が数字、ホーム列が修飾キーと矢印、下段がUndo/Cut/Copy/Pasteと Home/End/PgUp/PgDn |
| 2 SYM | 右T0（Enter）長押し | 記号（OSのキー配列はUS前提） |
| 3 FN | 右P4長押し | F1〜F12、音量、CPI±、QK_BOOT（両手のZ・/の位置）、EEPROM消去 |
| 4 MOUSE | 玉を動かすと自動で出る | 右手ホーム列：J＝左クリック、K＝中クリック、L＝右クリック、H と ; は押している間スクロール |

### ポインタの向きが合わないとき

`firmware/scissorball36/config.h` の次の2行を組み替えて再ビルドする（`make firmware QMK_HOME=...`、または qmk_firmware 内で `qmk compile -kb scissorball36 -km default`）。

```c
#define POINTING_DEVICE_ROTATION_90   // _180 / _270 に変える、または消す
#define POINTING_DEVICE_INVERT_X      // INVERT_Y に変える、または消す
```

センサーは玉を下から見上げる向きに付けるため、軸の向きは実物で確かめる必要がある。この2行は動作確認済みの値ではなく推定値。

## 8. 未検証の点・リスク

- **PG1425のフットプリント**：moduloindustries と shikamiya の公開フットプリント（実機での使用例あり）を基に作った。穴の大きさ（φ0.9/1.2）と底面突起の逃げ穴は、modulo が公開しているSTEPモデルで確かめたが、実物での確認はしていない。基板1:1 PDFで確かめてから発注すること。
- **レンズと玉の距離7.2mm**：PMW3360＋LM19-LSI の組み立てモデルから算出した。追従が悪い場合は次のどちらかで調整する：
  - 天井側ボスを削る（距離が縮む）か、ワッシャーを挟む（距離が伸びる）
  - `PMW33XX_LIFTOFF_DISTANCE` を変える
- **25mm玉の表面**：PA66球は表面が粗めで、POM球は安定しやすいという報告がある（TALP）。
- **3Dプリントの寸法**：ケースのSTLには細かい自己交差がある（Bambu Studioが自動修正する）。気になる場合はSTEPから読み込む。

## 9. 設計を変えるとき

`tools/layout.py` の数値（ピッチ、ずらし量、玉の位置、`TENT_DEG`/`TILT_DEG`）を変えて、リポジトリ直下で実行する。

```
make all KICAD_PY=<pcbnew が import できる python> FREECAD_PY=<FreeCAD が import できる python> FREEROUTING=<freerouting.jar>
```

個別のターゲット：`layout`（配置図）/ `outline`（基板外形）/ `pcb-left`・`pcb-right`（配置→自動配線→DRC）/ `production`（ガーバー）/ `case`（ケース）/ `check`（干渉チェック＋レンダリング）/ `firmware`

（KiCad 9.0、FreeCAD 1.0、Freerouting 2.0、QMK 0.34 で作成）
